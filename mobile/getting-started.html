移动端 · 快速开始 ​

目标：半天内把 delivery-template-uniapp 跑在微信开发者工具 / Android 真机上，并了解新客户项目的启动四步。

环境前置 ​

工具要求说明
HBuilderX实际使用 5.07（≥ uView 要求的 3.1.0）官网下载 App 开发版；本模板是 HBuilderX 工程（非 CLI），所有运行/打包都在 IDE 内
微信开发者工具最新稳定版运行小程序必需；需在「安全设置」开启服务端口，HBuilderX 才能拉起
Android 真机Android 8+ 建议调试 App 端需要；首次运行允许安装与 USB 调试
Node.js非必需HBuilderX 内置编译器；工程无 npm 构建链（package.json 仅为声明残留，见技术栈）

跑起来（两步） ​

  1. HBuilderX → 文件 → 打开目录 → 选择 delivery-template-uniapp；
  2. 运行：
    • 小程序：菜单「运行 → 运行到小程序模拟器 → 微信开发者工具」。首次会要求配置微信开发者工具安装路径；
    • App：手机连 USB（开启开发者模式与 USB 调试）→「运行 → 运行到手机或模拟器 → 运行到 Android App 基座」。标准基座即可跑通；用到自定义原生插件时需制作自定义基座（工程 nativeplugins/ 当前仅 google-services.json）。

环境切换

后端环境在 config/index.js 内按平台自动选择：小程序按 envVersion（开发版 → sso.dev01，正式版 → 生产），App 生产指向固定 IP。本地联调想走代理时，可写 uni.setStorageSync('proxyUrl', ...) 覆盖 baseURL（utils/request.js 优先读取）。

新项目启动四步（来自现有实践） ​

新客户项目 = 复制模板 + 四处修改：

  1. 复制 delivery-template-uniapp 整目录为新项目目录（派生关系记录到项目 README，避免出现第二个「权威模板」）；
  2. 改 manifest.json：name（新客户应用名）、appid（HBuilderX 重新生成，模板值为 __UNI__F0A5577）、mp-weixin.appid（客户的微信小程序 appid）、图标与启动图（源文件放 keystone_public/icon、keystone_public/splash）、Android 包名 app-plus.distribute.android.package（模板值为 uni.app.UNIF0A5577）；
  3. 加 prefix-rules 规则：在 utils/prefix-rules.js 的 PREFIX_RULES 中为客户增加一条（域名列表 + 前缀 + 需改写的路由；无特殊路由可置空数组，参考 cl 客户）；
  4. 服务端配置：在运营端为新租户配置菜单树与按钮权限（移动端菜单是运行时下发的，前端无需改动）。

App 打包与发布 ​

  • 入口：HBuilderX → 发行 → 原生 App-云打包（常用）/ 本地打包（离线 SDK，历史从 4.7.6 起维护）；
  • 签名与证书：keystone_public/签名/（develop / distribution 双环境，iOS 证书在 fanchang_IOS_证书/ 子目录）；
  • 安装包归档：keystone_public/安装包/（按应用市场分目录：360 / 安智 / 百度 / 苹果 / 应用宝）；
  • 版本号规则：manifest.json 的 versionName / versionCode 成对升级，规则如 2.4.2 ↔ 20402（主/次/补丁 × 10000 换算）；
  • 上架材料：截图各尺寸、软著、账号资料集中在 keystone_public/（截图/软著/各平台账号资料/授权文件）。

注意

keystone_public/ 已被 .gitignore 忽略且不在 git 仓库内——签名证书与安装包只存在于本机/归档盘，换机器前先确认备份。此风险已记入缺口分析（模板仓库化遗留项）。

常见问题 ​

  • 微信开发者工具拉不起来：检查工具的服务端口是否开启；HBuilderX 配置的安装路径是否正确；
  • 小程序请求 404 / 域名不合法：开发阶段在开发者工具勾选「不校验合法域名」；正式域名需在小程序后台配置 request 合法域名；
  • App 热更新不生效 / 版本不匹配：确认打包所用 HBuilderX 版本与线上 wgt 基线一致（README 记载 2.3.10 曾因 sdk 版本不匹配需用 5.07 重打包）；
  • pnpm dev:mp-weixin 跑不了：这是工程现状缺陷——dev:mp-weixin 在 package.json 里是顶层键不是脚本，npm 脚本方式不可用，统一走 HBuilderX 运行。
