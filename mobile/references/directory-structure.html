项目目录结构详解 ​

概述 ​

本文档详细介绍项目的目录结构，主要涵盖 pages 和 subPages 两大核心目录的组织方式和功能说明。

目录结构总览 ​

delivery-template-uniapp/
├── pages/           # 主页面目录（TabBar页面）
└── subPages/        # 子页面目录（非TabBar页面）

pages 目录结构 ​

概述 ​

pages 目录包含应用的主要页面，这些页面通常是底部导航栏（TabBar）中显示的页面，是用户最常访问的核心功能入口。

目录结构 ​

pages/
├── index/              # 首页模块
│   ├── index.vue      # 首页主组件
│   └── lang.js        # 首页多语言文件
├── mine/              # 个人中心模块
│   ├── index.vue      # 个人中心主组件
│   └── lang.js        # 个人中心多语言文件
├── navigation/        # 导航模块
│   ├── index.vue      # 导航主组件
│   ├── lang.js        # 导航多语言文件
│   └── api.js         # 导航相关API接口
└── notice/            # 通知模块
    ├── index.vue      # 通知主组件
    ├── lang.js        # 通知多语言文件
    └── api.js         # 通知相关API接口

模块详细说明 ​

1. index - 首页模块 ​

路径： pages/index/

功能：

  • 应用首页展示
  • 主要功能入口
  • 数据概览展示

文件说明：

  • index.vue - 首页主组件，包含页面布局和业务逻辑
  • lang.js - 首页多语言配置文件

主要特性：

  • 用户登录后的第一个展示页面
  • 提供快捷访问其他功能的入口
  • 显示重要通知和数据统计

2. mine - 个人中心模块 ​

路径： pages/mine/

功能：

  • 用户个人信息管理
  • 账户设置
  • 个人偏好配置

文件说明：

  • index.vue - 个人中心主组件
  • lang.js - 个人中心多语言配置文件

主要特性：

  • 显示用户基本信息
  • 提供账户设置入口
  • 管理用户偏好和配置

3. navigation - 导航模块 ​

路径： pages/navigation/

功能：

  • 应用内导航功能
  • 功能模块导航
  • 快捷入口管理

文件说明：

  • index.vue - 导航主组件
  • lang.js - 导航多语言配置文件
  • api.js - 导航相关API接口定义

主要特性：

  • 提供系统功能导航
  • 支持个性化导航配置
  • 与后端API交互获取导航数据

4. notice - 通知模块 ​

路径： pages/notice/

功能：

  • 系统通知展示
  • 消息提醒
  • 通知历史记录

文件说明：

  • index.vue - 通知主组件
  • lang.js - 通知多语言配置文件
  • api.js - 通知相关API接口定义

主要特性：

  • 显示系统通知和消息
  • 支持通知分类和筛选
  • 提供通知历史查询功能

subPages 目录结构 ​

概述 ​

subPages 目录包含应用的子页面，这些页面通常不是底部导航栏（TabBar）中的页面，而是通过导航跳转访问的功能页面。该目录按业务功能模块进行组织，结构清晰，便于维护和扩展。

目录结构总览 ​

subPages/
├── business/           # 业务功能模块
├── chart_page/        # 图表页面
├── static/            # 静态页面
└── system/            # 系统功能

业务模块详细说明 ​

1.1 env_mgmt - 环境管理 ​

功能： 监控和管理施工现场环境相关设备

包含模块：

  • smart_elec_meter - 智能电表管理，监控用电情况
  • smart_water_meter - 智能水表管理，监控用水情况

主要功能：

  • 实时监控环境设备数据
  • 历史数据查询和统计
  • 异常报警和预警

1.2 machinery_mgmt - 机械管理 ​

功能： 管理施工现场的机械设备和车辆

包含模块：

  • gantry_mon - 龙门架监控，监测龙门架运行状态
  • power_mon - 电力监控，监控电力消耗和设备运行
  • trans_mgmt - 运输管理，管理物料运输
  • veh_reg - 车辆登记，管理车辆信息和档案
  • wb_mon - 维保监控，监控设备维保状态

主要功能：

  • 机械设备档案管理
  • 运行状态实时监控
  • 维保计划和记录
  • 能耗统计和分析

1.3 personnel_mgmt - 人员管理 ​

功能： 管理施工现场的人员信息和相关活动

包含模块：

  • clockIn - 考勤打卡，管理员工考勤
  • meeting_mgmt - 会议管理，组织和管理会议
  • my_meeting - 我的会议，个人会议查看
  • online_exam - 在线考试，员工培训和考核
  • pers_reg - 人员登记，人员信息管理

主要功能：

  • 人员档案管理
  • 考勤管理
  • 培训和考核
  • 会议组织和管理

1.4 progress_collab - 进度协作 ​

功能： 协作管理项目进度和相关信息

通用文件说明 ​

文件类型说明 ​

.vue 文件 ​

  • 作用： Vue 单文件组件，包含模板、脚本和样式
  • 结构： <template> + <script> + <style>
  • 功能： 实现页面的UI展示和业务逻辑

lang.js 文件 ​

  • 作用： 多语言配置文件
  • 格式： JSON 格式的语言键值对
  • 功能： 支持国际化和本地化

api.js 文件 ​

  • 作用： API 接口定义文件
  • 功能： 封装与后端交互的接口调用
  • 特性： 统一管理模块相关的API请求

通用文件组织模式 ​

主要文件 ​

  • index.vue - 模块主页面
  • lang.js - 多语言配置文件
  • api.js - API接口定义

页面文件 ​

  • list.vue - 列表页面
  • detail.vue - 详情页面
  • edit.vue - 编辑页面

组件和资源 ​

  • components/ - 组件目录
  • static/ - 静态资源
  • utils/ - 工具函数

开发规范 ​

添加新页面（pages目录） ​

  1. 在 pages/ 下创建新目录
  2. 创建必需的文件：
    • index.vue (必需)
    • lang.js (推荐)
    • api.js (如需要API调用)
  3. 在 pages.json 中注册页面路由
  4. 添加多语言支持到 lang.js

添加新业务模块（subPages目录） ​

  1. 在对应的业务分类下创建新目录
  2. 创建必需的文件：
    • index.vue (必需)
    • lang.js (推荐)
    • api.js (如需要API调用)
  3. 遵循现有命名和组织规范
  4. 添加相应的路由配置

文件命名规范 ​

  • 组件文件：小写字母 + 连字符 (如 user-profile.vue)
  • 语言文件：统一使用 lang.js
  • API文件：统一使用 api.js
  • 主组件：统一使用 index.vue

模块分类原则 ​

  • 按业务领域分类
  • 保持模块独立性
  • 避免循环依赖
  • 统一代码风格
