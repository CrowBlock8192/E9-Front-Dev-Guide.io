🔧 迁移方法 ​

1. 组件复制 ​

bash
# 复制 uview-ui 组件
mkdir -p subPagePath/components/componentName
find uni_modules/uview-ui/components/componentName/ -maxdepth 1 -type f -exec cp {} subPagePath/components/componentName/ \;

# 复制全局组件
cp -r components/componentName subPagePath/components/

2. 引用路径更新 ​

javascript
// 原来的全局引用
import CuDropdown from '@/components/cu-dropdown/cu-dropdown.vue';

// 改为分包本地动态导入
components: {
  CuDropdown: () => import('../../components/cu-dropdown/cu-dropdown.vue'),
}

3. 批量更新脚本 ​

bash
# 删除全局import语句
find subPagePath -name "*.vue" -type f -exec sed -i "s|import ComponentName from '@/components/...'||g" {} \;

# 更新components引用
find subPagePath -name "*.vue" -type f -exec sed -i 's|ComponentName,|ComponentName: () => import('\''../../components/.../...vue'\''),|g' {} \;

✨ 迁移效果 ​

优化前 ​

  • 所有 uview-ui 组件打包进主包
  • 主包体积大，首屏加载慢
  • 分包无法独立运行

优化后 ​

  • 分包按需加载 uview-ui 组件
  • 主包体积显著减小
  • 分包独立性强，便于维护

🎯 下一步建议 ​

  1. 测试验证: 在微信开发者工具中测试所有分包页面功能
  2. 体积对比: 使用微信开发者工具对比主包体积变化
  3. 性能测试: 测试首屏加载时间和分包切换速度
  4. 清理工作: 清理未使用的全局组件引用

📝 注意事项 ​

  1. 组件依赖: 某些 uview-ui 组件可能有内部依赖，复制时需要确认完整性
  2. 样式文件: 确保组件的样式文件也一并复制
  3. 路径引用: 使用相对路径 ../../components/ 确保分包内引用正确
  4. 动态导入: 使用 () => import() 实现组件按需加载
