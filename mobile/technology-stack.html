i18n 特别说明（如实记录） ​

  • package.json 声明了 vue-i18n ^9.1.9，但全工程无任何 import——实际生效的是 utils/mixin.js 的自研方案：initI18n 按 uni.getStorageSync('lang') 装载词典，t(key) 查表翻译（zh 态直接返回原文 key，en 态查 locale/ 词典，缺词回退原 key 并 console 报错）；
  • locale/AppLang.js 以中文原文为 key 聚合 zh / en 词典（zh.js 约 113 条 / en.js 约 127 条），由 App.vue onLaunch 调用装载；
  • 与 PC 端 i18n 方案完全不同，跨端移植词条时不可直接照搬。

环境要求 ​

  • HBuilderX：工程无 engines 强制；uView2 自身要求 HBuilderX ^3.1.0；README 离线打包 SDK 更新链显示当前实际使用 5.07（历史：4.7.6 首次离线打包 → 4.87 → 5.04 → 5.07）。注意：App 热更新 SDK 版本需与 HBuilderX 版本匹配（README 记载 2.3.10 版曾用 5.07 重打包解决 sdk 不匹配）；
  • 微信开发者工具：运行、调试小程序必需；
  • Android 真机：调试 App 端需要；
  • package.json 里的 dev:mp-weixin 是顶层键而非 scripts 脚本（现状缺陷），不能以 pnpm dev:mp-weixin 方式运行；常规开发统一走 HBuilderX 的运行菜单（.hbuilderx/launch.json 内置 app-android / app-ios / mp-weixin 四套配置）。

选型说明与约定 ​

  1. uni-app Vue 2 现状：Vue3 迁移未立项。不要按 Vue3 语法假设读代码，也不要在需求或文档中虚构 Vue3 写法；uni-app Vue2 生态收缩风险与迁移规划见缺口分析 §4.3（遗留项，不承诺时间表）。
  2. uView 本地迁移版：UI 库不是 npm 依赖，而是 uni_modules/uview-ui 本地副本，且做过「全局加载 → 局部加载」迁移（按分包手动引入组件）。升级 uView 前必读迁移总结与迁移计划完整版。
  3. libs 离线包策略：dayjs / echarts / timezone / utc 以本地文件引入而非 npm 安装，规避 HBuilderX 工程依赖管理弱的短板；升级需手动替换文件。
  4. pap-* 组件族：自研业务组件统一 pap- 前缀 + easycom 自动注册（规则 "^pap-(.*)": "@/components/pap-$1/pap-$1.vue"），页面里无需 import。清单见功能开发。
  5. 统计关闭：manifest.json 的 uniStatistics.enable: false。
