PC 端 · 功能开发 ​

以「新增一个 CRUD 页面并跑通」为主线。代码样板：docs/templates/ 三个模板（下文逐段讲解），项目内同款样板在 src/views/backstage/template/ 与各业务页。

新增页面完整流程 ​

1. 建 views 目录 ​

在 src/views/business/keystone/<业务域>/ 下建功能目录（snake_case），一个功能一个目录。可从现有同类页面复制起步（或参考本文的三个模板）。

2. 写 api ​

在 src/api/<业务域>/ 下按业务主题建文件，函数命名 getXxxListApi / addXxxApi / editXxxApi / delXxxApi，JSDoc 中文注释 + @example：

js
import request from '@/utils/http';

/**
 * 回弹仪分页查询
 * @example POST /reboundmeter/query/page
 */
export function getReboundmeterListApi(params, data) {
	return request({ url: `/reboundmeter/query/page`, method: 'POST', params, data });
}

3. 配路由（二选一） ​

  • 动态路由（绝大多数业务页面）：前端不写路由代码，由服务端菜单下发。三步：
    1. 运营端「菜单元数据管理」新建菜单（组件路径填页面相对 views/ 的 localFilePath）；
    2. 「项目资源配置」勾选该菜单；
    3. 「菜单分类」勾选该菜单。 登录后 permission.js 调 getUserMenuApi 拉取菜单转路由（filterPermissionsRouters），详见SSO 登录链路。
  • 静态路由（登录页、个人页、样板页等固定页面）：在 src/router/routes/index.js 的 constantRoutes 中添加。

4. 页面三段结构 ​

CRUD 页面统一三段：查询区（search-bar）→ 表格（a-table）→ 弹窗/抽屉（编辑 + 详情）。完整骨架见下方模板讲解。

const listApi = async (params, data) => {
  const snapData = cloneDeep(baseData);
  console.log(data);

  let total = snapData.records.length;

  let start = (params.pageNumber - 1) * params.pageSize;
  let end = params.pageNumber * params.pageSize;
  snapData.records = snapData.records.slice(start, end);

  return {
    data: {
      records: snapData.records,
      total,
    },
  };

      pageNumber: pagination.current,
      pageSize: pagination.pageSize,

要点拆解：

段讲解
search-bar查询区容器，@query / @reset 回调，showExpand 展开更多条件；内部用 a-grid-item + a-form-item 排布
SectionSelect / AreaSelect标段 / 区域级联选择业务组件，equipmentType 过滤设备范围

tableDataAssign列定义与行数据对齐工具（@/utils）
弹窗三兄弟ApprovalDialog（发起审批）、EditDialog、DetailDialog 通过 ref.init(row) 打开；@onRefresh 回调刷新列表
column列定义抽到 ./utils/column.js，标题经 t() 翻译

vue
<template>
  <a-modal

          <a-input

          />
        </a-form-item>
        <a-form-item field="projName" :label="$t('附件')">
          <a-upload
            v-model:file-list="fileList"
            @before-upload="beforeUpload"
            :custom-request="customRequest"
            class="overflow-hidden"
            :limit="1"
          />
        </a-form-item>
      </a-form>
      <!-- <a-space class="mt-4 flex justify-end">
				<a-button @click="handleBeforeCancel">{{ $t('取消') }}</a-button>
				<a-button type="primary" @click="handleBeforeOk">{{ $t('仅保存') }}</a-button>
			</a-space> -->
    </a-spin>
  </a-modal>
</template>

<script setup>
import { ref } from 'vue';
import { Message } from '@arco-design/web-vue';
import {
  addScheduleApi,
  editScheduleApi,
} from '@/api/comprehensive/images-progress/images-config';
import { cloneDeep } from 'lodash-es';
import { beforeUpload, customRequest } from '@/utils/upload'; // 封装了通用的上传方法
import { formModelAssign } from '@/utils';
import { useCustomI18n } from '@/locale';
const { t } = useCustomI18n();

// 基本设置
const modalVisible = ref(false);
const modalTitle = ref(t('新增弹窗'));
const isEdit = ref(false);
const pageLoading = ref(false);

const emits = defineEmits(['onRefresh']);

const fileList = ref([]);

// 定义表单元素和数据
const formRef = ref(null);
const generateFormModel = () => ({
  id: null,
  sectionId: '',
  workPlace: '',
  validity: null,
  workContent: '',
});

const formModel = ref(generateFormModel());

const rules = {
  sectionId: [{ required: true, message: t('请选择所属标段') }],
  workPlace: [{ required: true, message: t('请填写作业区域') }],
};
// 弹窗初始化
const init = async (row) => {
  modalVisible.value = true;
  isEdit.value = !!row;
  modalTitle.value = !row ? t('新增弹窗') : t('编辑弹窗'); // !!row 为 true 时，!row 为 false，!!row 为 true，!
  if (row) formModel.value = formModelAssign(formModel.value, row);
};
// 确认操作
const handleBeforeOk = async () => {
  const res = await formRef.value?.validate();
  if (!res) {
    try {
      const apiCall = isEdit.value ? editScheduleApi : addScheduleApi;
      const data = cloneDeep(formModel.value);
      await apiCall(data);
      Message.success(`${isEdit.value ? t('编辑成功') : t('新增成功')}`);
      emits('onRefresh');
      handleBeforeCancel();
    } catch (error) {
      console.log(error);
      return false;
    }
  } else {
    return false;
  }
};

// 取消操作
const handleBeforeCancel = () => {
  handleReset();
  modalVisible.value = false;
  return true;
};

// 重置表单
const handleReset = () => {
  formModel.value = generateFormModel();
};

// 暴露子组件 对象/方法
defineExpose({
  init,
});
</script>

<style lang="scss" scoped></style>

要点拆解：

  • 新增/编辑复用同一弹窗：init(row) 有参 = 编辑（formModelAssign 回填），无参 = 新增；
  • a-modal 的 on-before-ok 里先 formRef.validate()，通过后按 isEdit 调 editXxxApi / addXxxApi，成功 Message.success + emits('onRefresh')；返回 false 阻止关闭；
  • 上传用 a-upload + @/utils/upload 的 beforeUpload / customRequest 通用方法（OSS 直传）；
  • 关闭时 handleReset() 恢复 generateFormModel() 工厂函数产出的初始值。

hooks 使用 ​

src/hooks/ 现有 9 个，页面逻辑优先复用，不要自写分页/权限逻辑：

hook用途
usePager分页状态 + pageRequest（最常用）
usePermissionhasPermission(str | str[]) 按钮级权限判断
useLoading / useRequestloading 状态 / 一次性拉取
useTimePicker / useTimeQuery时间范围选择 / 年季月日维度查询模型
useUser封装 logout + reload
useLocalei18next 无刷新切换语言
permissionHelperdefinePermission(resourcePath, customActions) 生成标准按钮权限码对象
