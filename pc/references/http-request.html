PC 端 · 请求封装参考 ​

行为规格基于 keystone-deliver-ui/src/utils/http/index.js（class HttpClient，2026-09-16 核对）。业务代码只经 @/utils/http 发请求，不要绕过。

基本参数 ​

项值说明
baseURLVITE_APP_BASE_API由 pnpm switch:api 写入
timeout120000 ms注意与基座 e9-delivery-ui 的 5000 不同
自动重试axios-retry：retries: 2，间隔 retryCount * 2000，shouldResetTimeout，仅超时（timeout）触发其他错误不重试

统一请求头 ​

基础头（始终携带）：Content-Type: application/json;charset=UTF-8、Accept-Language、.AspNetCore.Culture、timeZone（localStorage timezone，缺省浏览器时区）。

登录态头（handleAuthHeaders，有 token 才注入）：Authorization（getToken）、accountId、tenantId、Token-Type、lang（zh-CN→zh 否则 en）、tenantLang（租户语言，缺省 zh）。

特殊 baseURL 分流（REQUEST_TYPES 六种） ​

配置 requestType 的请求改走对应基址：geometry（几何）/ screen（大屏，取 BASE_API 去掉 /api）/ ezvideo（萤石）/ lecheng（乐橙）/ tplink / yunzhu（云筑）。geometry 与 yunzhu 跳过时间转换。

自动处理行为 ​

  1. 时间转时间戳：params / body 中的日期字符串（YYYY-MM-DD、YYYY-MM-DD HH:mm[:ss]，dayjs 严格校验）自动 .valueOf() 转时间戳；multipart/form-data 跳过；
  2. 大数安全：响应经 json-bigint 解析（storeAsString: true）+ 递归 BigInt→string，避免长 ID 精度丢失；
  3. 重复请求去重：去重键 = MD5([method, url, qs(params), qs(data)].join('&'))（crypto-js）——MD5 只用于去重键，不是签名；支持 cancelRepeat: 'before' | 'after' 与全局 cancelAllRequests()（AbortController）；
  4. 业务前缀改写：needsPrefix(VITE_BUILD_VIEWS, url) 按 ./prefix-rules 给命中的请求路径加业务前缀（多业务共用一套接口时的路由隔离）。

401 / 302 处理 ​

与基座不同，标品无弹窗、直接整页跳转：

text
HTTP 401 / 302
  ├─ tokenType === 'SHARE'（分享页）
  │    └─ 清 permission-store 后 reject，不跳转（降级）
  └─ 其他
       └─ 清 permission-store / tenantList / user-store + sStorage.clear()
          → window.location.href = `${addressUrl}/#/login?fromSite=${origin}`
          （location 模式且 VITE_APP_USE_SSO=true 时 addressUrl = VITE_APP_SSO_URL）

其余错误：Message.error(msg) 并 reject，业务侧 catch 处理。
